# 🎯 Quiz Application using Python

A simple and beginner-friendly **Quiz Application** developed using Python. The application displays multiple-choice questions, checks the user's answers, calculates the score, and displays the final result.

## 📌 Project Description

This project is designed to help beginners understand the basic concepts of Python programming through a simple quiz application.

The quiz contains multiple-choice questions with four options: **A, B, C, and D**.

The program:
- Displays each question
- Displays the available options
- Accepts the user's answer
- Checks whether the answer is correct
- Calculates the score
- Displays the final result

## ✨ Features

- 📝 Multiple-choice questions
- 🔤 A/B/C/D answer selection
- ✅ Automatic answer checking
- ❌ Displays the correct answer for wrong responses
- 📊 Automatic score calculation
- 🏆 Performance message based on score
- 💻 Runs directly in the Python terminal

## 🛠️ Technologies Used

- Lists

- `input()`

- Basic Python programming concepts
